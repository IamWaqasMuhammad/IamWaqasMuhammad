## ⚡ Fun Fact

> As a Flutter developer, I'm technically debugging a completely different reality than what users see.
> In **Debug Mode**, code runs on a JIT VM (slower, heavy overhead). In **Release Mode**, it compiles ahead-of-time (AOT) to blazing-fast native machine code.
> Meaning, half the performance bugs I fight only exist on my machine! 😄
